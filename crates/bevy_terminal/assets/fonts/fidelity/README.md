# Wide symbol regression fixture

`FidelityWideSymbols.ttf` is a renamed subset of regular Iosevka 34.8.1
(`Iosevka-Regular.ttf` from the release archive `PkgTTF-Iosevka-34.8.1.zip`,
SHA-256 `8b6065f04ca4ff4ce95ae48cf9f2f31b584823557adc38ec817dbe6f3745624b`).
Unlike Iosevka Fixed, its `↔∑∞◆★` are 1000-unit glyphs in a 500-unit
advance font: one terminal cell of occupancy with two cells of ink. The
subset keeps those, `⠿⣿`, and the renderer's measurement probes
(`()0W[]_agjpqy{|}ÅÉẪ█`); it carries no layout tables.

It is regenerated by `assets/fonts/fidelity/build_subsets.py` at the
repository root (fonttools 4.63.0), which pins the source hash; the
`glyph_coverage` maintenance test compares the subset's rasters with the
full font. Original copyright and license name records are retained;
the font is licensed under the accompanying SIL Open Font License
(`OFL.txt`). It is a test asset, not a renderer dependency.

# Nerd Fonts constraint fixture

`FidelityNerdSymbols.ttf` is a renamed subset of `JetBrainsMonoNerdFont-Regular.ttf`, the Nerd Fonts-patched JetBrains Mono that Ghostty vendors at `src/font/res/` (revision `b40acce58dcf77df52231c3798ea58e924647c89`, SHA-256 `a2f4268a1719b95d1f1448376173a42317919cb598423f18ea327eaca13dd916`). It keeps `0` and four icons that exercise Ghostty's Nerd Fonts constraints:

- U+2630 `☰` (cover at icon height);
- U+E0C0 (stretch; Powerline Extra Symbols, MIT);
- U+E60B (Seti UI, MIT);
- U+F408 (Octicons, MIT).

The last two use `fit_cover1`. The fixture has no layout tables.

It is regenerated by the same `build_subsets.py`, which pins the source hash. The JetBrains Mono copyright and OFL records are retained (`OFL.txt`); the icon sets keep their MIT licenses. It is a test asset, not a renderer dependency.
