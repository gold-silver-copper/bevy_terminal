# JetBrains Mono

This directory vendors the Regular, Bold, Italic, and BoldItalic static TTF faces from JetBrains Mono 2.304 for the crate examples;
the complete 16-face family lives in the `bevy_terminal_ratatui` root package.

- Source: <https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304>
- Archive: `JetBrainsMono-2.304.zip`
- Archive SHA-256: `6f6376c6ed2960ea8a963cd7387ec9d76e3f629125bc33d1fdcd7eb7012f7bbf`
- License: SIL Open Font License 1.1; see `OFL.txt`.

The files are used only by examples and visual-QA executables. The published
library depends only on Bevy.
